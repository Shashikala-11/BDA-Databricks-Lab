# Big Data Analytics Lab | Databricks

A collection of Big Data Analytics lab exercises and assignments completed using **Databricks** as part of my academic coursework.

## 📌 About the Project

This repository documents my practical work in Big Data Analytics, with lab exercises organized by experiment and supporting datasets and outputs.

The goal is to build hands-on familiarity with data processing, analytics workflows, and working with data in a cloud-based notebook environment.

## 🛠️ Technologies Used

* **Platform:** Databricks
* **Language:** Python / PySpark, where applicable
* **Data Processing:** Big Data Analytics tools and workflows
* **Version Control:** Git and GitHub

## 🚀 How to Explore

1. Clone this repository:

   ```bash
   git clone https://github.com/Shashikala-11/BDA-Databricks-Lab.git
   ```

2. Open the repository and navigate to the required lab folder.

3. Review the notebooks, datasets, and available outputs.

4. To execute the exercises, import the relevant notebook or code into your Databricks workspace and configure the required compute resources and dataset paths.
